# Lotto Lab

매주 로또를 구매한다고 가정하고 1등에 당첨될 때까지 걸리는 주 수와 누적 구매 비용을 시뮬레이션하는 Next.js 웹앱입니다.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 여세요.

## 빌드 및 배포

```bash
npm run build
npm run start
```

저장소를 Vercel에 연결하면 별도 환경 변수 없이 배포할 수 있습니다. Vercel은 Next.js 앱을 자동으로 감지합니다.

## 시뮬레이션 기준

- 로또 6/45의 전체 조합 수: 8,145,060
- 복권 한 장 가격: 1,000원
- 주간 당첨 확률: 구매 장수 ÷ 전체 조합 수 (번호 조합은 서로 다르다고 가정)
- 매 0.1초마다 최대 1,200주를 계산해 빠르게 진행합니다.

시뮬레이션은 재미와 확률 학습을 위한 도구이며 실제 당첨을 예측하거나 보장하지 않습니다.
